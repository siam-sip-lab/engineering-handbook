# Repository naming

## Rules

- **kebab-case**: lowercase English words joined by `-`.
- Name says **what it does**, not who made it or when.
- No people's names, years, or words like `new`, `final`, `test2`, `v2`.
- Fill in the repository **description** (one line) when creating it.
- Create new repositories from the org template (see M3) so standard files are included.

## Examples

| Good | Bad | Why bad |
| --- | --- | --- |
| `stock-checker` | `StockChecker` | capitals |
| `engineering-handbook` | `max-docs` | person's name, vague |
| `it-scripts` | `scripts_final_2026` | underscores, "final", year |
| `sales-dashboard` | `new-dashboard` | "new" stops being true |
